# HTML42 · Responsive Image & Content Showcase

响应式图文联动展示组件。直接打开 index.html 即可运行，无需安装依赖或联网。

- 缩略图、左右箭头及键盘方向键同步切换；首尾循环，默认不自动播放。
- 桌面左右布局，800px 及以下上下布局；所有幻灯片在 HTML 中维护。
- 图片采用本地 WebP 示意图，评价、评分均为虚构演示内容，正式使用时请替换。
- 修改 CSS 中 .showcase 的变量即可调整主题色、边框和间距。
- 添加项目时复制 article[data-slide] 及对应缩略图按钮，保持顺序和数量一致。
- 多实例可复制整个 section[data-showcase]；无需修改 JS。
- 无 JS 时展示全部内容；支持键盘操作及减少动态效果偏好。

# Interior Design Process Section

A responsive four-step process section for an interior design or creative services website.

## Layout

- Desktop: centered heading, four process cards in one row, and a full-width call-to-action panel.
- Tablet: process cards rearrange into a two-column grid.
- Mobile: heading, four cards, and CTA stack vertically.
- A thin orange connector line visually links the numbered steps on desktop.
- Uses a restrained warm-gray background, white cards, serif headings, and a terracotta accent.
- Built with standalone HTML and CSS; no framework or JavaScript dependency.

## Files

- `index.html` — semantic section markup and sample process content
- `css/style.css` — component styles and responsive breakpoints

## Customization

Edit the step titles and descriptions directly in `index.html`.
Change the content width, background, text, and accent colors through the CSS variables at the top of `css/style.css`.
Replace the `#contact` destination with the actual contact page or form URL when integrating.

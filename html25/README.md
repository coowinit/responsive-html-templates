# HTML25 — Interactive Roofing Services

## Preview
Open `index.html` in a browser.

## Structure
- `index.html` — markup
- `css/style.css` — responsive layout styles
- `js/script.js` — category switching behavior
- `images/` — local SVG image placeholders

## Features
- Four selectable roofing service categories (Commercial Roofing selected by default)
- Two images and matching text update when a category is selected
- Desktop two-column layout
- Mobile stacked layout with paired images
- Keyboard-operable category buttons and visible focus states
- CSS scoped to `#s25-roofing-services`

## Replace Images
Replace the SVG files in `images/` or update the image paths in `js/script.js`.
Keep the same filenames to avoid changing the page markup.

## Mobile Image Proportions
On mobile, the main image is intentionally taller than the secondary image. The gallery aligns both images to the bottom edge to preserve the staggered composition from the reference design.

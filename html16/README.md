# HTML16 — Five-Image Manufacturing Gallery

A self-contained, responsive HTML/CSS gallery using an asymmetric grid: one large featured panel and four smaller panels. This example uses inline SVG placeholders and does not require external image files, JavaScript, or a build system.

- Desktop: featured panel spanning two rows; four panels in a 2×2 arrangement.
- Tablet/mobile: featured panel full-width; remaining panels in two columns.
- Replace each placeholder SVG with an image when adapting the component to a real website.

Open `index.html` directly to preview the component.

Files: `index.html` and `css/style.css`.

# html36 — 全宽图片与响应式免费样品申请表单

独立响应式案例，适用于 B2B 外贸网站的免费样品申请、产品询盘、加盟咨询等场景。

## 布局原理

- 整个 Section 使用浅灰背景，不依赖上下其他页面区块。
- 桌面端：图片占左侧，贴齐浏览器最左边；右侧表单延伸至全站 1400px 内容容器的右边线。
- 屏幕宽于容器时右侧留白由 `calc((100vw - 1400px) / 2)` 自动计算。屏幕窄时保留安全边距。
- ≤991px：标题在上、图片居中、表单在下，避免移动端横向滚动。
- 表单在宽屏为两列，≤600px 改为单列。

## 修改参数

在 `.s36` 顶部修改：

- `--s36-container: 1400px`：与网站全局内容区最大宽度保持一致。
- `--s36-gutter: 24px`：大屏右侧最低留白。
- `--s36-background`、`--s36-accent`：背景和主题色。
- `--s36-image-position`：使用 `cover` 时图片的焦点位置。

替换图片只需修改 HTML 中 `images/sample-display.svg` 的路径。该 SVG 仅为场景占位图。

## 表单说明

该示例只提供前端字段验证和演示反馈，不会提交、发送或保存真实数据。正式部署时需要接入可信后端或 WordPress 询盘插件，并配置服务端校验、防垃圾提交和隐私提示。

表单使用标准 HTML 控件及独立 `.s36-` 样式，易于迁移到 WordPress 模板。正式站点可以将前端演示脚本替换为已有表单系统，不需要保留此演示提交逻辑。

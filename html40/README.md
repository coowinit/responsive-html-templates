# 3D SVG Responsive 404 Page

纯 HTML + CSS + 内联 SVG，无第三方依赖。打开 index.html 即可预览。

- 在 assets/css/style.css 的 :root 中修改品牌配色。
- 首页链接默认 `/`，部署在子目录时请按实际首页路径修改。
- 正式部署时由服务器或 WordPress 返回 HTTP 404；静态预览不负责设置响应状态。
- SVG 路径来自用户提供的 Atomik 商业主题页面源代码；此版本供本地研究与预览，公开再分发前请确认授权。

## 部署说明

演示按钮返回仓库预览首页。正式部署时请修改首页链接，并确保服务器返回 HTTP 404。原 SVG 来自参考商业主题，复用或再分发前请确认资源授权。

# html34 — 产品材料配方比例卡片

根据桌面及手机参考截图制作的独立响应式组件，适用于材料配方、技术组成、产品优势比例、项目数据等展示场景。

## 设计特点

- 桌面四列、平板两列、手机一列，手机端不出现半张卡片或横向溢出。
- 百分比标签悬浮于浅灰卡片左上角，具有清晰的视觉层级。
- 卡片内容按实际文本自适应高度，默认不强制等高；桌面四列保留轻微错落节奏，手机统一对齐。
- 仅使用原生 HTML/CSS，没有 JS、CDN、插件或字体依赖。
- 样式只作用于 `.s34` 内部，可整体复制到 WordPress 自定义 HTML 模块或主题模板中使用。

## 修改说明

- 修改标题、比例、卡片文案：编辑 `index.html`。
- 增加或减少卡片：在 `.s34-grid` 中复制或删除 `<article class="s34-item">`。
- 改整体宽度：修改 CSS 中 `--s34-max-width`，默认 1280px。
- 改卡片间距：修改 `--s34-gap`，默认 24px。
- 改背景色与百分比标签色：修改 `--s34-card-bg`、`--s34-accent`。
- 改百分比字号：修改 `--s34-badge-size`。
- 修改响应式断点：调整 CSS 中 1050px、700px 的媒体查询。

**注意**：当前比例与描述仅为布局演示，不代表实际产品配方或性能声明。上线前请确认真实数据与宣称依据。

## 使用

直接打开 `index.html` 预览。上传到 `responsive-html-templates/html34/` 后可通过 GitHub Pages 独立访问。

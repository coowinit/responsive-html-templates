# Reliable Solar Services

A responsive service-feature section with six cards, desktop hover states, and a simplified stacked mobile layout.

## Features

- Centered section title and supporting introduction text.
- Six service cards arranged in a 3-column layout on desktop.
- Hover/focus state on desktop shows a dark overlay background and a decorative image placeholder.
- No card is highlighted by default; the hover background appears only on desktop hover or keyboard focus.
- Touch/mobile layouts keep all text dark and readable, without hover or focus background effects.
- Mobile layout stacks cards vertically and removes the hover background treatment.
- No framework required.

## Files

- `index.html` — section markup
- `css/style.css` — desktop and mobile styles
- `images/service-hover-placeholder.svg` — decorative hover background placeholder

## Notes

- Replace the card titles, descriptions, and links as needed.
- On desktop, hover over a card or move keyboard focus to its link to preview the dark image-placeholder background.

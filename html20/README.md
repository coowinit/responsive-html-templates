# Solar Energy Feature Section

A responsive company introduction section for a solar and renewable energy business.

## Layout

- Desktop: two-column layout with an overlapping image composition on the left and company information on the right.
- Mobile: image composition appears first, followed by the title, description, service list, and call-to-action.
- Main image and secondary image use separate SVG placeholders.
- Maximum content width: 1200px.
- Built with standalone HTML and CSS; no framework or JavaScript dependency.

## Files

- `index.html` — section markup and sample content
- `css/style.css` — component styles and responsive breakpoints
- `images/solar-main.svg` — main solar image placeholder
- `images/solar-wind.svg` — secondary wind energy placeholder

## Customization

Replace the SVG files in `images/` with real photos, or update the image paths in `index.html`.
Edit the heading, description, service list, and CTA link directly in the HTML.

The green play icon is decorative in this static layout. Connect it to a video modal or video URL if video playback is required.
The `Learn More` link currently points to `#learn-more`; replace it with the destination URL when integrating.

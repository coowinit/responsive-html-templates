# html38 — 企业里程碑时间轴与卡片内图片轮播

独立可复用的响应式 HTML/CSS/JS 组件。无需网络连接或第三方脚本，直接打开 `index.html` 即可预览。

## 特点

- 电脑端约显示 3.3 张卡片、平板约 2.25 张、手机端约 1.2 张。
- 里程碑横向滚动：支持触摸板、触屏和上一张/下一张按钮；可聚焦轨道并按左右方向键。
- 每张卡片内嵌独立图片画廊；点击分页圆点或在图片内水平滑动即可切换图片。
- 年份范围、按钮禁用状态与底部进度条随滚动同步变化。
- 图片仅有一张时隐藏该卡片的圆点；案例数量过少时自动关闭无意义的导航。
- 8 个 WordPress 技术主题示例，采用灰底 + 图片图标 + 编号 PNG 占位图。

## 案例数量测试

直接打开：`index.html`（8 个案例）；也可在地址栏添加 `?count=1`、`?count=2`、`?count=3`、`?count=8` 检查少量案例。正式使用请增删 `assets/js/main.js` 的 `allMilestones` 数据条目。演示参数不是业务数据接口。

## 数据与图片

在 `assets/js/main.js` 的 `allMilestones` 中修改年份、标题、说明和图片数组。每个年份支持不同数量图片，图片路径相对于 `assets/images/`。PNG 占位图尺寸为 1200 × 750。

## 结构

```text
html38/
├── index.html
├── README.md
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── images/YYYY-NN.png
```

## 说明

为了离线可用和减少依赖，使用 CSS Scroll Snap + 原生 JavaScript 实现双层轮播，而非 Swiper 库。卡片内的图片滑动与外层卡片滑动在同一触屏手势上可能因设备不同而有所差异；分页圆点始终是明确的切换入口。页面所列年份代表演示内容主题安排，并非对应功能首次发布年份。

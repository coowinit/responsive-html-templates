# html28 · WordPress 优势交错时间轴

以“为什么选择Wordpress”为示例文案的响应式企业优势展示模块。

## 在线预览

https://coowinit.github.io/responsive-html-templates/html28/

## 使用方法

直接打开 `index.html`，或将对应 HTML 结构、`css/style.css` 和 `images/image-placeholder.svg` 复制到项目中。

- 桌面端：图片与文字左右交替，中央紫色数字时间轴。
- 移动端：左侧数字时间轴，右侧依次排列文字及图片。
- 标题采用 H2 主标题与 H3 条目标题；CSS 类名采用 `adv__` 前缀。
- SVG 为不含文字的灰色占位图，替换图片时保留容器的宽高比规则。
- 不依赖 JavaScript 或外部 UI 库。

该案例用于演示布局，实际使用时可按需要替换 WordPress 文案和图片。

# Basketball Club Introduction Layout

A responsive image-led introduction section with a four-item statistics row.

## Layout

- Desktop: large portrait image on the left; heading, description, and a second landscape image on the right.
- Mobile: portrait image, text, landscape image, then statistics in a two-column grid.
- Built with standalone HTML and CSS. No framework or JavaScript dependency.

## Files

- `index.html` — page structure and content
- `css/style.css` — responsive layout and styling
- `images/basketball-hoop.svg` — portrait placeholder image
- `images/basketball-player.svg` — landscape placeholder image

## Notes

This version uses two simple gray SVG placeholders with an image-style icon, making it easy to replace them later with real photos.

The statistics and copy are sample content from the supplied reference and can be edited directly in the HTML.
